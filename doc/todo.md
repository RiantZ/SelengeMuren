# Анализ: какие данные отсылают auto-trace и manual-trace (per trace/span)

## 2. Поля спана (map)

| Поле | Тип | auto-trace | manual-trace |
|---|---|:---:|:---:|
| `service` | str | ✅ (или nil) | ✅ |
| `name` | str | ✅ (или nil) | ✅ |
| `resource` | str | ✅ (или nil) | ✅ |
| `trace_id` | uint64 | ✅ (младшие 64 бита) | ✅ (младшие 64 бита) |
| `span_id` | uint64 | ✅ | ✅ |
| `parent_id` | uint64 | ✅ | ✅ |
| `start` | uint64 ns | ✅ | ✅ |
| `duration` | uint64 ns | ✅ | ✅ |
| `error` | int 0/1 | ✅ | ✅ |
| `meta` | map str→str | ✅ | ✅ |
| `metrics` | map str→double | ✅ | ✅ |
| `type` | str | ✅ (или nil) | ✅ |
| `span_links` | array | ❌ **не шлёт** | ✅ **13-е поле, если links есть** |
| `meta_struct` | — | ❌ | ❌ |
